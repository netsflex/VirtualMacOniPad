# Virtual Mac on iPad 2.2.0 beta 2 (1005)

版本名称：`2.2.0beta2`。构建号和 Debian 包版本：`1005`。

这是 [liukaixiang817/VirtualMacOniPad](https://github.com/liukaixiang817/VirtualMacOniPad) 的一个分支。与原版 Virtual Mac `com.mac.virtual` 冲突，在安装前需要卸载原版 Virtual Mac。虚拟机文件保存在 `/var/mobile/Media/VirtualMac`，卸载原版 Virtual Mac 不会删除它们。

下载二进制文件名：`VirtualMac2_2.2.0beta2_1005_standalone.deb`。

## 运行环境

- 只支持 rootless 越狱的 iPadOS 16.1 至 16.3.1，需要 ElleKit 或 libhooker。
- 实机验证：iPad Pro 11 (2021)（iPad13,5）、iPadOS 16.3.1、Dopamine 越狱环境，已测试过的版本为 macOS Seqoia 15.6.1, macOS 27.2, macOS 27.3 Developer Beta 1。

## 本版变化

相对 2.2.0beta1（1004）：

- 新增对 macOS 27 及以上版本系统的原生触摸屏支持，可在虚拟机设置中启用，默认仍使用指针模式。本版暂时仅适配 11 英寸 iPad 横屏的屏幕尺寸。
- 修复来宾系统重启后图形内存映射失效导致的黑屏卡死问题。
- 修复从其他应用导入自定义 IPSW 的权限问题，并修复了首次启动应用安装系统时 App 崩溃的问题。
- 修复 Guest Tools 在部分启动场景中反复安装的问题。
- 调整虚拟磁盘缓存与后台写回策略以提升部分场景下的 IO 性能。

## 安装

1. 正常关闭所有虚拟机，退出所有安装的 Virtual Mac 分发。
2. 安装：

   ```bash
   dpkg -i VirtualMac2_2.2.0beta2_1005_standalone.deb
   ```

   装有原版 Virtual Mac 时需要先卸载原版。
3. 注销（respring）一次，加载新的键盘插件。

## 已知问题

- 部分 GPU 负载渲染不正确，例如上述读取来宾 GPU 地址的特效（粒子等）无法显示。

## 构建

本版本的安装包为 `VirtualMac2_2.2.0beta2_1005_standalone.deb`，可用随附的 `SHA256SUMS` 校验。

从 macOS 提取并修改的 Apple 框架与上游发布包相同；它们不在本仓库的 MIT 许可范围内，也不随本仓库一同分发，所有使用该二进制构建的用户法律责任自负。
