# Virtual Mac on iPad 2.2.0 beta 1 (1004)

版本名称：`2.2.0beta1`。构建号和 Debian 包版本：`1004`。

这是 [liukaixiang817/VirtualMacOniPad](https://github.com/liukaixiang817/VirtualMacOniPad) 的个人修改版。它不再依赖原版 1.2.3：安装器、键盘直通插件和 NAT 网络组件都随包提供。包声明与 `com.mac.virtual` 冲突并替换它，安装时 dpkg 会自动卸载原版 1.2.3。虚拟机文件保存在 `/var/mobile/Media/VirtualMac`，卸载 1.2.3 不会删除它们。独立版的 NAT 网络和新建虚拟机安装 macOS 流程尚未在本版实测。

下载资产：`VirtualMac2_2.2.0beta1_1004_standalone.deb`。

## 运行环境

- 只支持 rootless 越狱的 iPadOS 16.1 至 16.3.1，需要 ElleKit 或 libhooker。
- 实机验证：M1 iPad Pro（iPad13,5）、iPadOS 16.3.1、Dopamine，来宾为 macOS 27.0.1。这不能推导出其它设备或来宾系统均已通过验证。

## 本版变化

相对 2.1.0beta1（1003）：

- 修复了含有 alpha 通道的 HEVC 视频硬解码失败的问题。
- 加入了 HEIC 图片的硬件加速解码支持。
- 添加了新的“妙控板”指针输入设备，可以在 iPad 原生支持的多点触摸板上透传触摸板事件以支持 macOS 的原生触摸板手势。

## 安装

1. 正常关闭所有虚拟机，退出所有安装的 Virtual Mac 分发。
2. 安装：

   ```bash
   dpkg -i --auto-deconfigure VirtualMac2_2.2.0beta1_1004_standalone.deb
   ```

   同时装有 1.2.3 和 Virtual Mac 2（1001）时需要 `--auto-deconfigure` 参数，
   因为 1001 构建声明依赖 1.2.3。
3. 注销（respring）一次，加载新的键盘插件。

## 已知问题

- 部分 GPU 负载渲染不正确，例如上述读取来宾 GPU 地址的特效（粒子等）无法显示。
- macOS Golden Gate 初次安装完成后 Dock 栏可能会崩溃无法显示，重启虚拟机后解决。

## 构建

本包可从本仓库和两个上游发布包复现。两个上游包是构建的输入原料，不是本版本的安装包：

| 上游包 | 来源 | SHA256 |
| --- | --- | --- |
| `VirtualMac_1.2.3.deb` | [nfzerox/VirtualMacOniPad 1.2.3](https://github.com/nfzerox/VirtualMacOniPad/releases/tag/1.2.3) | `435ce1dc76b9e18b1547c77b84e2cf33ffe40a16be63e366f181d14709a41aa0` |
| `VirtualMac_2.0.0beta1_1001.deb` | [liukaixiang817/VirtualMacOniPad 2.0.0beta1](https://github.com/liukaixiang817/VirtualMacOniPad/releases/tag/2.0.0beta1) | `853d6a92ead26f0e8cf001d0302f9211db5a676d5260ff4a45e18309e8800ed0` |

```bash
bash VirtualMac/scripts/development/build-virtualmac2-release.sh \
    VirtualMac_1.2.3.deb VirtualMac_2.0.0beta1_1001.deb output --build-number 1004
```

输出为 `output/VirtualMac2_2.2.0beta1_1004_standalone.deb`。

脚本先校验两个上游包的 SHA256，再从源码编译本 fork 修改或新增的所有组件，其余文件均原样取自上游包。

从 macOS 提取并修改的 Apple 框架与上游发布包相同；它们不在本仓库的 MIT 许可范围内，也不随本仓库一同分发，所有使用该二进制构建的用户法律责任自负。
